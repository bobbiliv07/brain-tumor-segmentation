# Brain Tumor Segmentation

Final year project focused on brain tumor segmentation using medical imaging data.

## Dataset

This project uses the **BraTS (Brain Tumor Segmentation) dataset**.

Please download the dataset from the **Synapse website**:

- https://www.synapse.org/

After downloading, place the dataset in the appropriate local data directory used by your notebooks/scripts.

## Repository Structure

- Jupyter Notebooks for data processing, model training, and evaluation.

## Getting Started

1. Clone this repository.
2. Download the BraTS dataset from Synapse.
3. Organize dataset files as expected by the notebooks.
4. Open the notebooks and run cells in order.

## Notes

- Access to BraTS data may require registration and acceptance of dataset usage terms on Synapse.
- Ensure you comply with all dataset licensing and usage requirements.
